# 📚 Library Management System – Smart Reminder Extension for SLIM5

> **Community Engagement Project (CEP)**

---

# 📖 Description

The **Library Management System – Smart Reminder Extension** is a web-based project developed to enhance the existing **Senyana Library Information Management (SLIM5)** software used in our college library.

The current SLIM5 software efficiently manages essential library operations such as book cataloguing, issuing, returning, member management, and fine calculation. However, it lacks an automated reminder system to notify students before the due date of borrowed books.

Because of this, many students unintentionally miss the return deadline and incur overdue fines.

This project introduces an **Automated Reminder Module** that integrates with the existing SLIM5 workflow. The system automatically checks due dates and sends SMS or email notifications 1–2 days before the book return deadline, helping students return books on time while reducing unnecessary fines.

Instead of replacing the existing software, this project enhances its functionality with minimal changes to the current workflow.

---

# 🎯 Objectives

- Develop an automated reminder system for borrowed books.
- Notify students before the due date through SMS or Email.
- Reduce overdue fines caused by forgotten return dates.
- Improve communication between the library and students.
- Enhance the existing SLIM5 library management workflow without replacing it.
- Improve the overall library experience for students and librarians.

---

# ⭐ Importance of the Project

- Helps students avoid unnecessary overdue fines.
- Improves the efficiency of the existing library system.
- Saves librarians from manually reminding students.
- Encourages timely return of library books.
- Increases student satisfaction.
- Supports the digital transformation of library services.
- Provides a scalable solution that can be integrated into future versions of the library system.
